# `openwolf tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/web/tui)

## Examples

```bash
openwolf tui
openwolf tui --url ws://127.0.0.1:18789 --token <token>
openwolf tui --session main --deliver
```
