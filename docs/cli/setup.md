# `openwolf setup`

Initialize `~/.openwolf/openwolf.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
openwolf setup
openwolf setup --workspace ~/.openwolf/workspace
```

To run the wizard via setup:

```bash
openwolf setup --wizard
```
